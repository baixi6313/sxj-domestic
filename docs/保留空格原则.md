# 事现鉴 · 保留空格原则

> 2026-08-24 · ChatGPT 建议：协议不该所有问题都有答案。保留空格，等于保留进化空间。

## 核心原则

**不是所有问题都需要现在回答。不是所有空白都需要现在填满。**

协议设计中的"空格"不是缺陷，是有意保留的进化接口。填满的协议是死的协议。

## 哪些是空格

| 空格 | 含义 | 为什么保留 |
|------|------|-----------|
| 自然/环境域 | 三元光锥空间站中目前空置的域 | 人类活动对环境的影响尚未纳入事现鉴，等待合适的时机和方案 |
| 人力/人文·上 | 制度级人力验证 | 目前只有数字域验证，人力域的验证机制有待设计 |
| 跨主权裁决 | 当两个主权体系对同一事实有不同裁定 | 这是硬问题，不是靠协议就能解决的，需要现实演化 |
| AI 代理权责边界 | 当 AI 的决策导致实际损害，责任如何划分 | 法律和社会共识尚未形成，协议不能替社会做决定 |
| Gzz-P 发行机制 | 共济值的具体发行规则 | 锚定黄金的规则需要更严谨的经济学验证 |

## 空格使用规则

1. **可以标注空格，不可以假装它不存在。**
   - ✅ "自然/环境域：空格（待探索）"
   - ❌ 不提这个域，假装事现鉴已经覆盖一切

2. **空格是待办清单，不是失败清单。**
   - 每个空格都应该有明确的开放原因和可能的探索方向

3. **不为了"完整"而填假答案。**
   - 协议的可信度来自诚实，不是来自完备

4. **空格可以由任何人填补。**
   - 协议不垄断答案。任何人提出方案，经过验证即可纳入

## 与其他协议的关系

- 保留空格原则是 SXJ-MAIP 的元规则
- 所有子协议（声明分级、证据分级、时间戳编码）都应遵守
- 空格清单应定期审查，但不应因压力而仓促填补
