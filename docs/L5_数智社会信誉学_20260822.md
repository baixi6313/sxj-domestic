# 数智社会信誉学

> 数智社会工程 · 第5层 · 核心问题：信用怎么计量和流通？
> 由砺整理 · 2026-08-22

---

## 一、学科定义

**数智社会信誉学**是研究在数智社会中，如何记录、量化、验证和流通一个人的跨主权公开信用的学科。

它回答三个核心问题：
1. 什么样的贡献值得被记录？（价值计量）
2. 被记录的贡献怎么量化？（信誉评分）
3. 被量化的信誉怎么流转和使用？（价值流通）

## 二、理论基础：三值模型

### 2.1 公式

```
社会总净值 = GzzA + GzzB - C

其中：
  GzzA = 共济值（Cohesion Value）——个体对社会的共济贡献
  GzzB = 贡献值（Contribution Value）——个体的专业/创造性贡献
  C    = 负贡献（Negative Contribution）——损害社会信任的行为
```

### 2.2 三值详解

| 值 | 含义 | 来源 | 示例 |
|----|------|------|------|
| **GzzA 共济值** | 个体参与社会协作、维护信任网络的能力 | 交互验证网络中的正面验证记录 | 参与验证、提供可靠证据、协助他人 |
| **GzzB 贡献值** | 个体在专业领域创造的可验证价值 | 专业产出 + 同行验证 | 开源代码、研究论文、公共服务 |
| **C 负贡献** | 损害社会信任的行为 | 被验证的虚假陈述、恶意破坏 | 伪造证据、操纵验证、欺诈 |

### 2.3 与寰宇光锥舟"贡献值"的区别

| | 事现鉴三值之 B（贡献值） | 寰宇光锥舟"贡献值" |
|---|---|---|
| 范围 | 事现鉴协议内 | 文明贡献经济体系 |
| 计量 | 协议内可验证 | 跨文明尺度 |
| 关系 | 三值模型的组成部分 | 独立的经济哲学概念 |

> 参见 Gzz 同名异义第 4 条：贡献值（寰宇光锥舟·文明贡献经济）≠ 事现鉴三值之 B。

## 三、信誉计量方法

### 3.1 ρ 值（信誉密度）

```
ρ = conf × sourceIndep × evidenceGrade × roleWeight

其中：
  conf        = 置信度（0-1），由验证网络共识程度决定
  sourceIndep = 来源独立性（1-5），独立来源越多越高
  evidenceGrade = 证据等级（E1=5, E2=3, E3=1）
  roleWeight  = 角色权重（验证节点权重，人类 > Agent）
```

### 3.2 证据分级

| 等级 | 定义 | 权重 | 示例 |
|------|------|------|------|
| E1 | 可独立复现的公开事实 | 5 | 官方公告、公开数据、可复现实验 |
| E2 | 多方交叉验证的间接证据 | 3 | 媒体报道 + 社交平台 + 第三方确认 |
| E3 | 单一来源、待验证 | 1 | 匿名举报、未确认线索 |

### 3.3 信誉积累路径

```
初始状态（GzzA=0, GzzB=0, C=0）
    │
    ├─ 参与验证 → GzzA 逐步增长
    ├─ 产出可验证贡献 → GzzB 逐步增长
    └─ 虚假陈述被验证 → C 增加，拉低总净值
    │
    ↓
ρ 值随验证次数和时间自然演化
```

## 四、Gzz 消费币机制

### 4.1 定位

Gzz 消费币是信誉的流通载体，不是独立货币。

- **锚定**：1:1 e-CNY 备付
- **性质**：使用权凭证，非所有权凭证
- **防超发**：发行量不超过备付金余额

## 五、跨主权信用验证

### 5.1 核心原则

- **不自行定价**：系统只记录验证结果，不赋权值
- **主权定价**：各法域/机构基于自身标准解读 ρ 值
- **可验证性优先于权威性**：ρ 值可被任何节点独立复核

### 5.2 与传统征信的区别

| | 传统征信 | 数智社会信誉学 |
|---|---|---|
| 数据来源 | 金融机构单向上报 | 多主体交互验证 |
| 评分权 | 中心化机构 | 分布式验证网络 |
| 纠错机制 | 申诉→人工审核 | 存根链 + 多源交叉验证 |
| 激励 | 借贷便利（负向约束） | 信用积累（正向激励） |
| 主权 | 国家/机构垄断 | 跨主权、可互认 |

### 5.3 与传统金融的区别

- **无投机**：Gzz 不是投资品，不产生息差
- **无杠杆**：不基于信用创造衍生品
- **无息差**：流通的是使用权，不是资本
- **金融是工具，不是目的**：Gzz 消费币仅服务于信誉的流转
