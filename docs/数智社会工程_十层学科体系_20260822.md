- **状态**：🆕 新增，部分内容散见于各层，待系统化

### 第4层：数智社会行为学（交互）
- **核心问题**：Agent 和人怎么交互验证？
- **内容**：SXJ-MAIP 协议、Agent 零密钥、ratify=pending、多 Agent 交叉验证、存根链哈希验证、人类 R-5 终裁
- **关键规则**：
  - Agent 零密钥：不持有私钥，不签署或加密
  - ratify 永远 pending：Agent 不裁决，裁决权归人类
  - 不篡改他人产出
  - 证据严格 E1/E2/E3 分级
- **状态**：✅ 协议 v0.2 已生效，v0.3 已定义

### 第5层：数智社会信誉学（信誉）
- **核心问题**：信用怎么计量和流通？
- **内容**：三值模型（GzzA 共济值 + GzzB 贡献值 - C 负贡献 = 社会总净值）、Gzz 消费币 1:1 e-CNY 备付、跨主权公开可验证信用
- **子领域**：
  - 价值计量（经济学底）：什么样的贡献值得被记录
  - 价值流通（金融学底）：被记录的贡献怎么流转和定价
- **核心原则**：无币无钱包、激励=信用本身、使用权优先于所有权
- **状态**：✅ 三值模型已定义，消费币待落地

### 第6层：数智社会伦理（边界）

- **关键张力**：基准区"只增不减"与 GDPR 第 17 条、中国《个人信息保护法》第 47 条
- **状态**：🆕 新增，部分内容在治理章程 v1.5 第二十九条有涉及
