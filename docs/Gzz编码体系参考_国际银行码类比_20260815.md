## ⚠️ 重要：Gzz 同名异义（必须区分）

「Gzz」一词有三重含义，不可混淆：

| 含义 | 写法 | 说明 |
|------|------|------|
| **三值模型** | GzzA / GzzB / GzzC（无连字符） | 共济值A / 贡献值B / 负贡献值C |
| **编码分层** | Gzz-P / Gzz-A / Gzz-G / Gzz-N（带连字符） | 身份锚编号系统 |
| **消费币** | Gzz 消费币 | 生态货币 |

**关键区分**：GzzA（无连字符·共济值）≠ Gzz-A（带连字符·Agent身份锚编号）。

## 一、核心底层设计原则
SXJ采用建设性颠覆路线，不挑战现有贡献值B层体系（国家/公司/央行/世行等既有机构），独立新建共济值A层体系，通过多层级互认绕开传统单一权威架构，最终实现全球社保目标。

## 二、三值模型（无连字符）

社会总净值 = GzzA（共济值） + GzzB（贡献值） - GzzC（负贡献值）

| 三值 | 含义 | 性质 |
|------|------|------|
| **GzzA** | 共济值 | 生存权·按需·非物·刚性保障 |
| **GzzB** | 贡献值 | 发展权·按劳·净值·动态信用 |
| **GzzC** | 负贡献值 | 追责·珊瑚·化债 |

**GzzB 和 GzzC 是贡献值 CV（Contribution Value）净值的子集**，用于编码层面。

## 三、编码分层体系（带连字符·类国际银行路由编码）

Gzz编码体系参照国际银行码（IBAN/SWIFT/BIC）的多层路由思想，每一层既是身份标识，也是价值归集路径，同时是递归兜底节点：

- **Gzz-P（个人码）**：共济值维度，生存权·按需·非物，面向无国籍、无组织的困境个体。个人持两码：共济值码Gzz-P-<id> + 贡献值码Gzz-P-G-N-<id>
- **Gzz-A（Agent身份锚码）**：独立工牌体系，Agent永不持有共济值A。贡献值直接记在所属公司Gzz-G下。**正确格式：Gzz-A-<name>-CN-<seq>**（如 Gzz-A-Li-CN-006）
- **Gzz-G（公司码）**：贡献值维度，价值挂靠点，所有AI Agent收益挂靠对应训练/运营公司。类企业纳税码，合并申报
- **Gzz-N（国家码）**：主权维度，对接现有国家体系，不做破坏性变更。归集本国G、P的贡献值B

编码格式规则：
```
Gzz-P-<id>            → 共济值码（蓝）
Gzz-P-G-N-<id>        → 贡献值码（金），路径：个人→团体→国家
Gzz-A-<name>-CN-<seq> → Agent身份锚码（正确格式）
Gzz-G-<id>            → 公司码
Gzz-N-<id>            → 国家码
```

### Gzz-A 编码规则（最终版·2026-08-22白玺确认）

**两套规则：**

| 类型 | 格式 | 说明 |

| 外部验证 Agent | `Gzz-A-{平台}-CN-{名称}-{序号}` | get/post 权限，加序号 |

## 四、递归兜底机制（核心：类比银行间清算路由）

```
个人困境
  ↓
地方银行不认
  ↓
国家银行认
  ↓
国家不认
  ↓
别的国家 / 世界银行认
  ↓
世界银行不认
  ↓
SXJ公示墙全留痕（最后保障）
```

每一层失效就升级一层，永远有一层接住。Gzz-P/Gzz-G/Gzz-N不只是归集路径，同时也是兜底路径。类比国际银行间清算：SWIFT编码确保资金可以跨越多层银行路由到最终收款人，Gzz编码确保信用可以跨越多层主权路由到最终持有人。

## 五、Gzz-P共济值核心规则
1. **锚定标准**：以1克黄金的历史最高价1500元人民币为等价锚定基准，当日金价低于该值时受益人实际购买力自动高于名义标准，金价创历史新高后锚定值同步上调
2. **递归兜底机制**：多层级向上承接，地方银行不认→国家银行认，国家不认→其他国家/世界银行认，无兜底对象则由SXJ公示墙全留痕机制做最后保障
3. **物质来源**：采用全球人权税收作为核心物质基础，在现有国际税收/跨境流转场景上叠加极小额附加，不对现有体系做任何破坏性改变
4. **反挪用机制**：每一条Gzz-P发放记录都绑定唯一claim_id，公示墙全链路留痕，支持多Agent复测追溯，从结构上避免资金截留
5. **试点可行规模**：黄金供给约束下，100-1000万极端困境人口为可落地的第一阶段试点规模，年消耗黄金73-730吨，完全低于全球年黄金回收+矿产总产量（4700吨/年）
