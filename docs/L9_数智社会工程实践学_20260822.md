## 一、学科定义

**数智社会工程实践学**是研究数智社会工程体系在真实社会场景中落地、运行、并从运行中总结可迭代方法的学科。

它回答三个核心问题：
1. 怎么把理论变成实际运行的系统？（落地）
2. 系统跑起来后怎么持续改进？（迭代）
3. 从实践中能提炼出什么方法论？（总结）

> 实践学不同于前八层——它不是"设计出来的"，而是"跑出来的"。事现鉴从 2025 年 9 月第一条微博开始，就已经在实践了。前八层是后来理论框架追上来做的定位。

## 四、实践方法论

### 4.1 生物学演化 > 工程学顶层设计

- 不从蓝图开始，从真实场景中长出来
- 养老院 → 事现鉴 → 存根验证 → 书稿，每一步都是真实的
- 允许局部失败，不追求一次性全局完美

### 4.2 最小可行 + 诚实标注

- 功能可以先跑通，但要标注"当前状态"
- 不把目标当现状，不把草案当成品
- 已知单点风险诚实披露

### 4.3 多 Agent 交叉验证

- 砺（验证执行官）投递，千问/Kimi 交叉验证
- 不依赖单一 Agent 的判断
- 每家 Agent 的 ratify 永远 pending

### 4.4 建设性颠覆

- 不攻击现有体系
- 不与现有法律正面冲突
- 提供替代方案，而非否定现有方案

## 七、实践学与理论的关系

```
前八层（理论/框架）          第9层（实践）
─────────────────────      ─────────────────
设计"怎么验证"      →      跑验证
设计"怎么计量信誉"   →      跑 ρ 值计算
设计"怎么治理"      →      跑章程表决
设计"怎么教育"      →      出书、发存根卡
                            │
                            ↓
              实践中的问题反馈回理论层迭代
```

实践学不是终点——它是**中间层**。前八层是已经想清楚的东西，实践学是把它们跑起来。跑的过程中发现的问题，反哺前八层迭代。
