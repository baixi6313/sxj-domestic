## 六、技术说明


### 6.1 哈希链算法


```

SHA256(title | description | event_time | prev_hash)[:8]
```

与现有 chain.json（196条术语编码）使用的完全相同的哈希算法，保证链的连续性和可验证性。

### 6.2 编码格式


**事件编码（文档类）：**

```

Gzz-E-GOVERN-CHARTER-PROTO-{timestamp}-{seq}-{hash8}

```

**政策锚点编码（v2.0 source_ref 扩展）：**

```

Gzz-E-GZZP-ISSUE-{timestamp}-{seq}-{hash8}

+ source_ref = [{ type: 'policy', ref_id: 'Gzz-POL-{ORG}-{DOC}-{ART}', url: '...' }]

```

### 6.3 向后兼容


- 旧记录（前196条）无 source_ref 字段，读取时自动视为空列表

- 新增记录包含 source_ref 字段，用于承载政策锚点引用和外部来源链接

- 哈希算法保持不变，整条链可独立验证
