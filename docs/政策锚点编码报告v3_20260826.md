## 四、哈希算法说明

**Gzz v2.1 三项锚定哈希：**

```python
import hashlib

def gzz_hash(content, event_time, prev_hash):
    seed = f"{content}|{event_time}|{prev_hash}"
    return hashlib.sha256(seed.encode()).hexdigest()[:8]
```

- **content** = term 字段文本内容
- **event_time** = YYYYMMDDHHMMSS 格式时间戳
- **prev_hash** = 上一条记录的 current_hash（8位）
- **full_sha256** = 完整64位 SHA-256 哈希值

**编码格式：**

- 文档：`Gzz-E-DOC-CHARTER-{YYYYMMDDHHMMSS}-{序号3位}-{哈希8位}`
- 政策锚点：`Gzz-E-GZZP-ANCHOR-{YYYYMMDDHHMMSS}-{序号3位}-{哈希8位}`
