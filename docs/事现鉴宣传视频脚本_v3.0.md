## 序章：寰宇光锥舟（0:00 — 3:00）

### 画面

**0:00-0:30**
纯黑。寂静。

一个白色光点在画面正中心亮起，缓慢脉动，像心跳。第一次脉动扩散一圈微弱引力波，第二次更强，第三次光波延伸到画面边缘。

光点周围没有任何其他物体。深空。

**0:30-1:30**
光点向右侧射出三道光束——金色向上偏前约30度，蓝色向下偏后约30度，珊瑚红向下偏前约30度。光束逐渐扩展为三个锥形光场，锥尖汇聚于白色光点。

光锥内开始浮现稀疏的粒子，缓慢流动。金色光锥内粒子偏暖，像尘埃在阳光中飘浮；蓝色光锥内粒子偏冷，像数据流；珊瑚红光锥内粒子偏红橙，像火星余烬。

镜头缓慢拉远，三个光锥的全貌逐渐显现——它们构成一个三角形的空间结构，白色光点是唯一的交汇点。

**1:30-2:30**
画面中央开始浮现文字，白色细体：

```
2025年9月5日
一条微博发出
只有四个字
```

文字逐行淡入淡出。最后四个字放大、停留：

```
寰宇光锥舟
```

**2:30-3:00**
光锥缓慢旋转。旁白开始。

## 第一幕：三独占（3:00 — 8:00）

### 画面

**3:00-4:00**
光锥消散。画面切换到现实蒙太奇——

- 学术论文页面弹出付费墙："您需要订阅才能查看此文章"
- 专利检索网站，密密麻麻的专利号，但全文需要付费/授权
- 手机APP里的用户协议弹窗，"同意"按钮高亮，"拒绝"按钮灰掉
- 社保查询页面需要实名认证+人脸识别
- 医保系统里，你的就诊记录你自己导不出来
- 平台后台，用户行为数据以可视化图表滚动，但用户本人看不到
- 一位研究者在图书馆，翻到一本需要付费的期刊，叹气
- 一位小企业主，想查一项专利是否侵权，发现专利数据库年费几万

画面逐渐加速，信息越来越密集，声音从嘈杂变成白噪音。

**4:00-5:00**
所有画面静止。碎裂成粒子，被三个方向吸入。

三个光锥重新出现。但这一次，光锥的入口处各有一扇门——

- 金色光锥的门上挂着一把锁，锁上刻着"知识"
- 蓝色光锥的门上挂着一把锁，锁上刻着"技术"
- 珊瑚红光锥的门上挂着一把锁，锁上刻着"经验"

三扇门紧闭。粒子在门前堆积，无法进入。

**5:00-6:30**
镜头依次推进三扇门。每扇门前浮现表格——

第一扇门（金色）：

```
知识独占
独占主体：学术数据库、出版集团
被锁定的内容：论文、研究成果、引用数据
```

画面：付费墙弹窗、机构登录界面、动辄数百元的单篇论文下载费、大学每年向数据库支付的巨额订阅费账单。

第二扇门（蓝色）：

```
技术独占
独占主体：国家专利库、企业/个人专利
被锁定的内容：技术方案、使用方法、授权记录
```

画面：专利文书的特写、"专利侵权"律师函、企业专利墙、制药公司专利到期前的 evergreening 策略。

第三扇门（珊瑚红）：

```
经验独占
独占主体：平台、各国社保/医保系统
被锁定的内容：行为记录、经验分享、用户轨迹、社保记录
```

画面：平台数据后台、用户画像标签云、社保窗口排队、医保数据无法跨院转移、骑手困在系统算法里。

**6:30-8:00**
三扇门同时震动。粒子越积越多，光锥内的光在门后闪烁——那是本该被共享的人类知识、技术和经验，但被锁住了。

旁白最后一段时，三扇门上的锁开始出现裂纹。画面浮现文字：

```
使用权 > 所有权
```

### 旁白

> 人类积累了七十年的规则、几千年的知识、几百年的技术。
>
> 但大部分人接触不到。
>
> 不是因为不存在。是因为被锁住了。
>
> **第一把锁，叫知识独占。**
>
> 学术论文锁在付费数据库里。出版集团把本该属于全人类的研究成果，以每年数百万的订阅费卖给大学。一个研究者想读同行的论文，要付费；一个小企业主想查一个行业标准，要付费。知识的创造者——学者、研究者、纳税人资助的科研项目——不拥有自己产出的分发权。
>
> **第二把锁，叫技术独占。**
>
> 技术方案锁在专利库里。专利制度本应保护创新者，但现实是，大公司用专利墙围堵竞争者，用"evergreening"策略延长垄断，用专利流氓敲诈小企业。技术方案写在专利文书里，但你要使用，就得付费，或者被告。
>
> **第三把锁，叫经验独占。**
>
> 你的行为记录、消费轨迹、社交关系、就诊历史、社保缴费——这些由你自己产生的数据，被锁在平台的后台和政府的系统里。平台用你的数据训练模型、精准广告、算法定价，但你自己看不到、带不走、删不掉。你骑了一万单外卖的经验属于平台，不属于你。你交了三十年的社保记录，跨个省都查不到。
>
> 三独占——知识独占、技术独占、经验独占——锁住的不是信息本身，而是普通人的判断力。
>
> 你连事实都接触不到，拿什么判断真假？
>
> 你连数据都看不到，拿什么验证断言？
>
> 你连自己的经验都不属于自己，拿什么建立信用？
>
> 这就是寰宇光锥舟要渡的那条河。
>
> 河的对岸，不是一个乌托邦。是一个最简单的常识——
>
> **使用权，应该优先于所有权。**

### 屏幕文字

```
三独占
知识独占 · 技术独占 · 经验独占

论文锁在付费墙后面
技术锁在专利墙后面

```

## 第二幕：共创论（8:00 — 13:00）

### 画面

**8:00-9:30**
三扇门上的裂纹扩大。金色、蓝色、珊瑚红三色光从裂纹中透出。

白色光点脉动一次，引力波扩散，三扇门同时碎裂。粒子涌入光锥，开始流动。

画面变成生物学隐喻——一颗种子在土壤中发芽，根系向三个方向延伸（金色、蓝色、珊瑚红），根须相互缠绕。与旁边一棵整齐栽种的人工林形成对比：人工林排列整齐但脆弱（一倒一片），种子自然生长但根系深厚（互成网络）。

镜头在两套生态之间反复对比：人工林 = 顶层设计、围墙花园、集中控制；自然根系 = 演化生长、开放互联、分布式韧性。

**9:30-11:00**
三条主张以粒子书写的方式逐条浮现在光锥之间：

第一条：
```
使用权 > 所有权
```
画面：知识从围墙中流出，像水一样灌溉根系。论文、标准、数据从付费墙后飞出，化为金色粒子进入光锥。

第二条：
```
记录 > 定价
```
画面：天平一端是硬币（在消散），另一端是刻着编码的石板（在发光）。硬币化为碎屑，石板上的编码越来越多。

第三条：
```
验证 > 信任
```
画面：一个握手的剪影碎裂，替换为一条由编码组成的链。链上每个节点都可以被放大镜检视，放大镜下显示原始来源和哈希值。

**11:00-13:00**
画面展示价值三层系统。三张卡片从光锥中心依次浮现：

第一张（金色边框）：
```
GzzA 共济值
定值 · 生存权 · 按需分配 · 不可剥夺
对应：法币（基础保障）
```

第二张（蓝色边框）：
```
GzzB 贡献值
净值 · 发展权 · 按劳分配 · 可变化
对应：数字货币（动态）
```

第三张（珊瑚红边框）：
```
C 负贡献值
扣减项 · 追责 · 修复 · 对冲
对应：债务 / 自然损益
```

三张卡片组成一个等式：

```
净值 = GzzB - C
GzzA = 定值（不参与计算）
```

### 旁白

> 三独占的锁碎了之后，需要一套新的规则。
>
> 这套规则叫共创论。
>
> 共创论不推销真理。它不给你答案，它给你一套免疫系统——让你在面对任何断言时，有能力自己判断：这是谁说的？依据是什么？谁来验证？
>
> 共创论的设计思路来自生物学，不是工程学。
>
> 工程学喜欢顶层设计——画好蓝图，打好地基，一层层盖上去。高效，但脆弱。一个环节出错，整栋楼摇晃。
>
> 生物学相信演化——一颗种子落进土壤，根系向有水的地方延伸，枝叶向有光的地方生长。慢，但有韧性。环境变了，它跟着变。
>
> 事现鉴选择生物学路径。不挑战现有体系的既得利益，不推翻重来，而是在三独占的废墟上，长出一座桥。
>
> 这座桥有三个桥墩。
>
> **第一，使用权优先于所有权。**
>
> 论文的版权可以保护，但论文的阅读权不该被付费墙锁死。技术可以申请专利，但技术标准必须公开。你的数据你有权查看、导出、删除。创造价值的人拥有署名权，但使用价值的人不需要申请许可。
>
> **第二，不自行定价，只记录主权定价。**
>
> 不做裁判，不做评级机构，不给任何实体打分。只记录：谁在什么时候声称自己做了什么，对应什么标准，证据在哪里。价格由市场定，由主权定，不由平台定。
>
> **第三，走跨主权公开可验证的信用路线。**
>
> 不依赖任何单一平台、单一政府、单一公司。信用不来自权威背书，而来自一条公开的、不可篡改的、任何人可以顺着编码追溯到源头的链。
>
> 共创论还定义了价值的三层：
>
> **GzzA，共济值。** 定值。生存权，按需分配，不可剥夺。它对应的是法币体系中的基础保障——每个人活着就有，不因为你做了什么或没做什么而增减。
>
> **GzzB，贡献值。** 净值。发展权，按劳分配，可变化。你创造了价值，贡献值增加；它对应的是数字货币体系中的动态计量。
>
> **C，负贡献值。** 扣减项。追责、修复、对冲。你造成了损害——污染、侵权、欺诈——C增加，从GzzB中扣减。它对应的是债务和自然损益。做错事不是打个分就完了，要修复，要对冲，要追责。
>
> 共济值不参与计算。它是底线。
>
> 贡献值减去负贡献值，等于净值。
>
> 这不是乌托邦。这是一个把账算清楚的方法。
>
> 共创论是"道"。但道需要"术"来落地。
>
> 术，叫事现鉴。

```
共创论
不推销真理 · 提供免疫系统

生物学演化 > 工程学顶层设计
建设性颠覆 · 不挑战既得利益

使用权 > 所有权
记录 > 定价
验证 > 信任

GzzA 共济值 = 定值（生存权·不可剥夺）
GzzB 贡献值 = 净值（发展权·可变化）
C 负贡献值 = 扣减项（追责·修复·对冲）
```
