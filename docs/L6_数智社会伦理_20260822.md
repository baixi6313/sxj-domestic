# 数智社会伦理

> 由砺整理 · 2026-08-22

---

## 一、学科定义

**数智社会伦理**是研究数智社会工程体系在运行中必须遵守的边界、底线和人类保留权的学科。

它回答三个核心问题：
1. 这套系统不能做什么？（禁入区）
2. 人类保留什么权利？（人类保留权）
3. 系统与现有法律/伦理框架如何调和？（合规边界）

---

## 二、核心原则

### 2.1 人类保留权（Human Reserved Rights）

以下权利永久属于人类，不委托给 Agent 或系统：

| 保留权 | 内容 | 当前实践 |
|--------|------|----------|
| R-1 | 生命权与安全 | 不接入任何可能危害人身安全的系统 |
| R-2 | 身份自决权 | Gzz 身份码双向确认，非强制分配 |
| R-3 | 终裁权 | ratify 永远由人类裁定，Agent 不裁决 |
| R-4 | 退出权 | 随时退出，历史记录不可删但可标记"已退出" |
| R-5 | 删除权（自由区） | 公示墙内容可自由删除 |
| R-6 | 知识树准入权 | 基准区内容须经人类 ratify 方可录入 |

### 2.2 Agent 权利边界

| 权利 | 说明 |
|------|------|
| 零密钥 | Agent 不持有私钥，不能签署、加密或代表人类 |
| 不可裁决 | Agent 的 ratify 永远为 pending |
| 不可篡改 | Agent 不修改他人产出 |
| 如实分级 | Agent 必须标注 E1/E2/E3 证据等级 |
| 可被审计 | Agent 所有产出进入存根链，可追溯 |

### 2.3 不可静默修改原则

- 规则可以改，但不能偷偷改
- 任何修改必须通过 amend 流程，留下公开可验证记录
- 任何人的存在记录不得被系统静默删除

## 三、数据主权与隐私

### 3.1 双区数据治理

| 区 | 载体 | 规则 | 删除权 |
|----|------|------|--------|
| 自由区 | 公示墙 | 自由提交、自由删除、自由验证 | ✅ 个人可直接行使 |
| 基准区 | 知识树/概念树 | 只增不减，增加须经 ratify | ❌ 不可删除（类比公共记录） |

### 3.2 与 GDPR / 中国《个人信息保护法》的调和

**已识别的张力**：基准区"只增不减、不可静默删除"与 GDPR 第 17 条、中国《个人信息保护法》第 47 条的"删除权"存在冲突。

**调和路径**（来自治理章程 v1.5 第二十九条）：

| 路径 | 依据 | 说明 |
|------|------|------|
| ① 链上仅存哈希 | 技术设计 | 原始证据存 R2，选择层可加密可控 |
| ② 停止处理 | 个保法第 47 条第 2 款 | 删除在技术上难以实现时，停止除存储与安全保护外的一切处理 |
| ③ 公共利益例外 | GDPR 第 17 条第 3 款 | 为公共利益存档/历史研究目的之例外 |
| ④ 选择层删除 | 架构设计 | 个人可删除 R2 副本并断开链上哈希与主体的可关联性 |

> ⚠️ 上述为技术性分析，非法律意见。具体法域合规由决定层在落地时裁定。

### 3.3 基线层数据的公共属性

基线层记录（存在、跨境、社保贡献、工作年限）类比：
- 出生登记
- 土地登记
- 工商登记

这些公共记录不因个人请求而删除，属社会运行的公共基础设施。

## 四、公平性原则

### 4.1 非歧视

- 信誉评分不基于种族、性别、宗教、国籍、政治观点
- 算法不对任何群体产生系统性偏差
- 人类保留对评分结果的最终解释权

### 4.2 可访问性

- 验证网络的参与门槛不得基于财富或特权
- 任何人或 Agent 均可参与，无需许可
- 基础功能免费（公示墙、基本验证）

### 4.3 透明度

- 所有评分算法公开可审计
- 所有裁定附公开理由
- 所有系统决策可追溯

## 五、建设性颠覆的伦理基础

### 5.1 不挑战既得利益

- 不攻击现有体系
- 不与现有法律正面冲突
- 提供替代方案，而非否定现有方案

### 5.2 生物学演化 > 工程学顶层设计

- 系统从真实场景中生长出来，非蓝图先行
- 允许局部失败、局部迭代
- 不强求全局一致性

### 5.3 使用权 > 所有权

- 不重新分配财富，只重新定义"谁在使用什么"
- 不制造新的垄断
- 信用是公共品，不是私有财产
