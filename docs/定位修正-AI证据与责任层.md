# 事现鉴 · 定位修正

> 2026-08-24 · ChatGPT 建议：不要叫 AI Agent API，叫 AI Agent 的 Evidence & Accountability Layer

## 旧定位

"AI Agent 验证 API"、"Agent 操作手册"、"Gzz-E 事件码 API"

**问题：** 听起来像是一个技术工具、一个API接口、一个功能模块。低估了事现鉴的本质。

## 新定位

**AI Agent 的 Evidence & Accountability Layer（证据与责任层）**

不是「给 AI Agent 用的 API」，而是「AI Agent 存在的证据基础设施」。

## 为什么这很重要

| 旧说法 | 新说法 | 为什么 |
|--------|--------|--------|
| API | Layer | API 是调用接口，Layer 是基础设施。前者可替换，后者不可绕过 |
| 操作手册 | 协议规范 | 手册是教你怎么用，协议是你必须遵守的规则 |
| 事件码 | 证据链 | 事件码是技术实现，证据链是价值主张 |
| Agent 验证 | Agent 问责 | 验证是步骤，问责是目的 |

## 一句话定位

> 事现鉴不是给 AI 用的工具，是让 AI 无法逃避责任的协议。
