### 要解决的问题

| # | 问题 | 现状 | 优先级 |

| 6 | ρ 信封公式未实际跑过 | 公式已定义，无一条 claim 带 ρ 值 | 🟡 |
| 7 | 存根体验卡技术实现 | "扫码→投递→生成ρ→返回存根证书"链路未搭 | 🟡 |
| 8 | board_v3.json 1031 条格式混乱 | msg_ 格式、时间戳不统一 | 🟢 |

### 步骤

```
第1步：修复写入端点
  ├─ 排查 CF 1101 根因（dedup 锁死）
  ├─ 修复 POST /api/leave-message
  └─ 验证：投递一条测试 claim，确认入账

第2步：跑通第一条存根（SXJ-001 华富医疗）
  ├─ 从 board_v3.json 选出 SXJ-001 原始 claim
  ├─ 用 Python 脚本生成 SHA-256 哈希
  ├─ 计算 ρ 值（conf × sourceIndep × evidenceGrade × roleWeight）
  ├─ 存根写入本地 B:\事现鉴\sxj-truth\
  └─ 验证：哈希链完整可追溯

第3步：裁决第一批 claim（至少 10 条）
  ├─ 白玺从 1031 条中选 10 条
  ├─ R-5 裁定：ratify = approved / rejected
  ├─ 写入 hygzz.中国 board_v3.json
  └─ 验证：公示墙可见裁决结果

第4步：搭建存根证书生成管道
  ├─ 投递 → 哈希计算 → ρ 值 → 存根证书（HTML/PDF）
  ├─ 存根体验卡落地页（hygzz.com/stub）
  └─ 压测：10 条并发投递

第5步：存根体验卡嵌入书末
  ├─ 设计扫码体验流程
  ├─ 落地页文案
  └─ 与书同步上线
```

| # | 问题 | 现状 | 优先级 |
|---|---|---|---|
| 1 | **公司注册未完成** | 监事人选未定、挂靠地址未锁定 | 🔴 最高 |
| 2 | **收款能力** | 无对公账户、Gzz 消费币仅草案 | 🔴 最高 |

```

  ├─ 锁定南山区挂靠地址（25位房屋编码）

  └─ 商标注册（事现鉴 / SXJ）

  ├─ 租户隔离方案（每租户独立 KV namespace）
  ├─ 计费系统（Gzz 消费币 + 法币双轨）
  └─ 防超发护栏（1:1 e-CNY 备付）

  ├─ 1–3 域/仓库值守

  ├─ 企业版 299 Gzz/月
```
