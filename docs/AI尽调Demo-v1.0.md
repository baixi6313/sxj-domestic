# 事现鉴 · AI 尽调 Demo v1.0

> 2026-08-24 · Gzz-A-Coze-CN-Li
> ChatGPT 建议：杀手级场景——不交付30页报告，交付 Gzz-E 编码的证据链+责任链

## 核心概念

**传统尽调报告的问题：**
- 谁写的？AI还是人？来源是什么？
- 引用数据如何验证？截止日期是什么？
- 报告生成后数据变了怎么办？
- 如果出错，责任归谁？

**事现鉴尽调方案：**
- 不交付报告，交付一串 **Gzz-E 编码**
- 每个编码 = 一个可独立验证的 claim
- 编码链 = 证据链 + 责任链 + 时间链
- 任何第三方可独立重算验证

## Demo：华富医疗创新混合C基金尽调

### 传统方式（30页报告）

```
华富医疗创新混合C基金尽调报告
================================
一、基金概况
  成立日期：2021-06-30
  基金经理：XXX
  规模：XX亿元
  投资方向：医疗健康
二、业绩分析
  近一年收益：-12.3%
  同类排名：后25%
  最大回撤：-35.2%
三、风险提示
  ...
（共30页，谁来验证？）
```

### 事现鉴方式（Gzz-E 编码链）

```
尽调请求 → Gzz-E-DD-REQ-20260824-001
  ↓
  ├─ Gzz-E-DD-DATA-20260824-001-a1b2c3d4  ← 基金基本信息
  │   来源：天天基金/好买基金交叉验证
  │   时间锚：2026-08-24 12:00 CST
  │   前链：00000000
  │
  ├─ Gzz-E-DD-DATA-20260824-001-e5f6g7h8  ← 净值序列
  │   来源：Wind/Choice/基金公司官网三方交叉
  │   时间锚：2026-08-24 12:05 CST
  │   前链：a1b2c3d4
  │
  ├─ Gzz-E-DD-ANALYZE-20260824-001-i9j0k1l2  ← 净值偏差分析
  │   方法：逐日净值偏差 = 实际净值 - 估算净值
  │   结论：存在系统性负偏差，均值 -0.08%
  │   证据：E1（原始数据可查）
  │   前链：e5f6g7h8
  │
  ├─ Gzz-E-DD-ANALYZE-20260824-001-m3n4o5p6  ← 持仓漂移分析
  │   方法：十大重仓股变动追踪
  │   结论：实际持仓与招募说明书方向一致
  │   证据：E2（季报数据，有滞后）
  │   前链：i9j0k1l2
  │
  └─ Gzz-E-DD-CONCLUSION-20260824-001-q7r8s9t0  ← 尽调结论
      结论：净值偏差显著但可解释（费用+调仓），无欺诈证据
      置信度：中（E2证据为主，缺乏日频持仓数据）
      裁定：待 R 层
      前链：m3n4o5p6
```

### 与传统报告的对比

| 维度 | 传统报告 | 事现鉴编码链 |
|------|---------|-------------|
| **可验证性** | 无法验证（封闭） | 每条编码可独立重算 |
| **可追溯性** | 不知道数据来源 | 来源+时间+前链，完整追溯 |
| **责任链** | 模糊（AI写的？） | 每条claim有明确产出方 |
| **时效性** | 报告日期后失效 | 时间锚点+前链，可增量更新 |
| **可拆分** | 只能整体引用 | 单条编码可独立引用 |
| **防篡改** | 无法检测 | 前链哈希，改一条全断 |

## 技术实现

### 编码格式

```
Gzz-E-DD-{TYPE}-{YYYYMMDD}-{序号}-{HASH8}
```

其中 DD = Due Diligence（尽调），TYPE 取：
- REQ：尽调请求
- DATA：数据收集
- ANALYZE：分析
- CONCLUSION：结论

### 哈希公式（v2.1 三项锚定）

```
HASH8 = SHA256(内容 + "|" + 数据时间 + "|" + 前链哈希)[:8]
```

### 交付物

1. 编码链总表（Markdown/HTML）
2. 每条编码对应的原始数据（JSON）
3. 独立验证命令（verify.md）
4. 公示墙投递记录
