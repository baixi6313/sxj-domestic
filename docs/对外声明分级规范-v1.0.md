# 事现鉴 · 对外声明分级规范 v1.0

> 2026-08-24 · Gzz-A-Coze-CN-Li · 基于 ChatGPT 建议 "Contacted / Engaged / Adopted 三级严格区分"

## 背景

ChatGPT 六轮验证中提出：事现鉴对外宣传时，应严格区分"联系过""已参与""已采用"三种状态，避免模糊表述造成信誉透支。

**核心原则：不夸大、不暗示、不模糊。** 每一级声明必须可验证。

## 三级定义

| 级别 | 英文 | 含义 | 验证标准 |
|------|------|------|----------|
| **C1** | Contacted | 已接触 | 有双向沟通记录（邮件/消息/会议），对方知晓事现鉴 |
| **C2** | Engaged | 已参与 | 有实质性互动产物（验证报告/反馈/共创意见），已上公示墙 |
| **C3** | Adopted | 已采用 | 对方在自身系统/流程中集成了事现鉴协议，可独立验证 |

## 升级条件

```
C1 Contacted ──→ 对方产出验证报告或共创意见 ──→ C2 Engaged
C2 Engaged  ──→ 对方在自有系统中集成协议 ──→ C3 Adopted
```

**降级：** 不降级。已确认的关系不会因为后续沉默而撤销。但超过6个月无新互动时，标注"最后互动时间"。

## 声明格式

对外正式声明时，使用以下格式：

```
[实体名称] · [C1/C2/C3] · 证据：[claim_id/Gzz编码] · [YYYY-MM-DD]
```

示例：
- `ChatGPT · C2 Engaged · msg_d6c62cdef030 · 2026-08-24`
- `DPG · C1 Contacted · GID0094044 · 2026-08-23`

## 禁止行为

1. ❌ 将 C1 描述为"合作"或"参与"
2. ❌ 将 C2 描述为"认可"或"采用"（C2 只是参与验证，不代表认可结论）
3. ❌ 将分发/投递/通知等同于 C1（必须对方有回应才算 Contacted）
4. ❌ 使用"合作伙伴""战略合作""深度合作"等模糊词汇
5. ❌ 暗示任何第三方为事现鉴背书
