# 数智社会教育

> 数智社会工程 · 第8层 · 核心问题：怎么让更多人掌握？
> 由砺整理 · 2026-08-22

---

## 一、学科定义

**数智社会教育**是研究如何将数智社会工程的知识、方法和工具传播给更多人，使其能够理解、参与和贡献于数智社会建设的学科。

它回答三个核心问题：
1. 教什么？（知识体系）
2. 怎么教？（传播路径）
3. 谁可以参与？（参与门槛）

---

## 二、教育目标

### 2.1 分层目标

| 层次 | 目标 | 受众 |
|------|------|------|
| 认知层 | 知道数智社会工程的存在和意义 | 公众 |
| 理解层 | 理解三值模型、信誉学、验证机制 | 潜在参与者 |
| 参与层 | 能够投递 claim、参与验证 | 验证节点 |
| 贡献层 | 能够开发工具、维护协议 | 协议维护者 |
| 创造层 | 能够提出新理论、新方法 | 研究者 |

### 2.2 核心素养

一个"数智社会公民"应具备：
- 理解使用权 > 所有权的含义
- 能区分共济值和贡献值
- 能独立验证一条 claim 的证据等级
- 知道自己的数据在自由区还是基准区
- 能看懂存根链的哈希验证逻辑

## 三、知识体系

### 3.1 入门路径

```
第1步：读《数智社会工程学》（书稿）
  ├─ 了解愿景（寰宇光锥舟）
  ├─ 理解理论（共创论）
  ├─ 掌握框架（三值模型、Gzz 体系）
  └─ 看到实践（Autopilot、公司化）

第2步：体验存根验证
  ├─ 扫码书末"存根体验卡"
  ├─ 投递一条自己的 claim
  ├─ 看到 ρ 值生成
  └─ 收到存根证书

第3步：成为验证节点
  ├─ 注册 Gzz 身份码
  ├─ 参与至少 3 条 claim 的验证
  └─ 获得 ρ 值

第4步：深入参与
  ├─ 提案（治理章程第十三条）
  ├─ 开发工具
  └─ 成为协议维护者
```

### 3.2 课程模块（草案）

| 模块 | 内容 | 对应层级 |
|------|------|----------|
| 数智社会导论 | 为什么需要？什么是数智社会？ | 第0-1层 |
| 数智社会工程学原理 | 三值模型、Gzz 体系、同名异义 | 第2层 |
| 交互验证方法 | Agent 行为规则、证据分级、ρ 值 | 第4层 |
| 信誉计量与流通 | 信誉学、Gzz 消费币、定价 | 第5层 |
| 伦理与边界 | 人类保留权、数据主权、公平性 | 第6层 |
| 治理与参与 | 章程、决策机制、修宪 | 第7层 |
| 实践工作坊 | 投递 claim、存根生成、验证 | 第9层 |

## 四、传播路径

### 4.1 书稿出版（第一阶段）

- **载体**：《数智社会工程学》（v1.0 定稿后出版）
- **策略**：书末夹"存根体验卡"，读者扫码即进入第2步
- **目标**：建立第一个认知漏斗——书读者 → 存根体验者 → 验证节点

### 4.2 存根体验卡（第二阶段）

- **载体**：二维码 → hygzz.com/stub 落地页
- **体验流程**：扫码 → 投递一条 claim → 生成 ρ 值 → 收到存根证书
- **设计原则**：零门槛、即时反馈、可带走

### 4.3 公示墙（持续）

- **载体**：hygzz.中国/board.html
- **功能**：公开可见的验证记录，任何人可浏览
- **教育价值**：让"可验证"变得可见

### 4.4 社区协作（持续）

- 验证节点之间的自然协作
- 维护者文档和教程
- 开源工具和脚本

## 五、参与门槛设计

### 5.1 零门槛原则

- 任何人或 Agent 均可参与，无需许可
- 公示墙自由提交、自由删除
- 基础验证功能免费

### 5.2 渐进式深度

| 行为 | 门槛 |
|------|------|
| 浏览公示墙 | 零门槛 |
| 投递 claim | 零门槛 |
| 参与验证 | 需 Gzz 身份码（自动生成+双向确认） |
| 提案 | 需验证节点资格 |
| 维护协议 | 需经决定层确认 |
| 知识树录入 | 须经人类 ratify |
