## 全局风格设定

```
视觉风格：深色太空背景(#050510)，金色(#D4A843)、蓝色(#2563eb)、珊瑚红(#FF6F61)三色光锥体系。
整体质感：科技感、宇宙感、克制、不煽情。参考Three.js 3D粒子+星云美学。
字体：无衬线体，中文用思源黑体/PingFang SC，英文用Segoe UI。
音乐：低频环境音+渐入电子脉冲，不使用激昂配乐。
旁白：男声，低沉平稳，语速偏慢，类似纪录片解说。
转场：粒子聚合/消散，不使用花哨切屏。
```

## 第一段：寰宇光锥舟（0:00-0:45）

### 画面

深空。黑色背景上，远处有微弱星光。

一个白色光点从画面中央亮起，缓慢脉动。光点向外扩散引力波圆环，一圈、两圈、三圈。

旁白开始时，光点向右侧射出三道光束——金色向上偏前、蓝色向下偏后、珊瑚红向下偏前。三道光束逐渐扩展为三个锥形光场，锥尖汇聚于白色光点。

光锥内开始浮现稀疏的粒子，缓慢流动。

### 旁白

> 2025年9月5日，一条微博发出。
>
> 只有四个字——寰宇光锥舟。
>
> 寰宇，是我们身处的世界。光锥，是物理学术语——任何事件能影响到的时空范围。舟，是渡过去的载体。
>
> 这不是一个产品的名字。这是一个问题：
>
> 在信息洪流中，在算法推荐里，在真假难辨的公共话语空间里——普通人靠什么不被忽悠？

### 屏幕文字

```
寰宇光锥舟
2025.09.05
```

（白色细体，居中，淡入淡出）

## 第二段：共创论（0:45-1:35）

### 画面

三个光锥缓慢旋转。金色光锥内开始凝聚出文字碎片和人形轮廓——宣言、条约、对话气泡，以粒子形态聚合又散开。

画面中心的白色光点持续脉动，引力波扩散到三个光锥中，驱动粒子流动。

蓝色光锥内浮现代码流、网络节点、协议握手的抽象动画。

珊瑚红光锥内浮现地球轮廓、气候数据流、供应链网络。

### 旁白

> 问题之后，是理论。
>
> 共创论不推销真理。它不给你答案，它给你一套免疫系统——让你在面对任何断言时，有能力自己判断：这是谁说的？依据是什么？谁来验证？
>
> 它有三个底层主张：
>
> 第一，使用权优先于所有权。知识、数据、验证能力，不该被锁在围墙里。
>
> 第二，不自行定价，只记录主权定价。不做裁判，做记录者。
>
> 第三，走跨主权公开可验证的信用路线。不依赖任何单一平台、单一政府、单一公司。
>
> 共创论是"道"。但道需要"术"来落地。

### 屏幕文字

```
共创论
不推销真理 · 提供免疫系统

使用权 > 所有权
记录 > 定价
验证 > 信任
```

（逐行淡入，金色）

> 事现鉴，是共创论的工程实现。

>
> 坐标有上中下：制度级、组织级、个人级。
>
> 这不是分类学。这是一张时空地图——你能看到每一个事实在整个人类治理体系中的位置。
